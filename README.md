# Personal OpenAI-Compatible ChatGPT Local API Server 🚀

سيرفر محلي متكامل ومرن يحوّل أتمتة Playwright لموقع ChatGPT إلى API متوافق 100% مع واجهة برمجة تطبيقات **OpenAI** المعيارية (`POST /v1/chat/completions`)، مدمج مع **ملفات باتش آلية (Batch Files)** لتثبيت وتشغيل كافة الخدمات بضغطة زر واحدة دون الحاجة لإعادة تنفيذ أية أوامر يدوية مستقبلاً.

---

## 🌟 الميزات الرئيسية

- **مشغل الملف التنفيذي (Batch Files Automation)**: اختصار آلي شامل؛ بنقرة واحدة فقط يقوم بتنظيف الجلسات القديمة، تشغيل سيرفر Python، وتأمين النفق الخارجي دون كتابة أية أوامر في التيرمينال.
- **بث مباشر لحظي حقيقي (Real-Time SSE Streaming)**: يدعم نمط البث `stream: true` مع نقل الكلمات والقطع في الوقت الفعلي أثناء كتابة ChatGPT في المتصفح، مما يلغي انقطاع الاتصال نهائياً (`Zero Timeout`).
- **انتظار ديناميكي مرن (Dynamic Generation Waiting)**: يراقب كتابة ChatGPT ديناميكياً ويسمح بتوليد الإجابات الضخمة جداً (أكثر من 60KB) دون أدنى حد زمني قسري أو قطع.
- **توافق معيار OpenAI الرسمي**: يعمل مباشرة مع جميع الملحقات (Plugins)، منشئي المواقع (Site Builders)، وأطر عمل الذكاء الاصطناعي (مثل TypingMind, LangChain, AutoGen, Firebase, NextChat).
- **عزل تام للذاكرة ومنع التكرار**: تصفية مكررات البرومبت، وتطهير مدخلات النص قبل كل طلب لحماية سياق المحادثة.
- **استراتيجية جلب النص المبتكرة الرباعية**:
  1. البث اللحظي للقطات الـ DOM المتطورة
  2. زر النسخ المباشر والحافظة (Clipboard)
  3. اعتراض حزم بيانات شبكة الـ API (`backend-api/*`)
  4. خطة طوارئ لاستخراج النص الخام لآخر `<article>`
- **مرونة واستعادة تلقائية (Auto-Recovery)**: في حال إغلاق أو انهيار متصفح Playwright، يعيد السيرفر فتح المتصفح تلقائياً دون سقوط السيرفر.
- **مرونة الأنفاق والبدائل**: يدعم الربط عبر **Ngrok (رابط ثابت)**، **Cloudflare Tunnel**، **LocalTunnel**، أو **Firebase Functions**.

## ⚡ ملفات التشغيل والتحميل التلقائية (One-Click Bat Files)

لتسهيل الاستخدام على أي جهاز دون الحاجة لفتح التيرمينال أو كتابة أوامر، يتوفر ملفان:

1. 📦 **`Install_Requirements.bat`** (ملف التثبيت والتحميل - يُشغل مرة واحدة):
   - يفحص وجود Python في الجهاز.
   - يثبت جميع المكتبات من `requirements.txt`.
   - يثبت متصفح Playwright Chromium تلقائياً.

2. 🚀 **`Run_Server.bat`** (ملف التشغيل اليومي):
   - ينظف العمليات العالقة في الخلفية.
   - يشغل سيرفر الـ API على المنفذ `8008`.
   - يفحص ويشغل نفق Ngrok تلقائياً إن كان متوفراً.

## 🛠️ دليل التثبيت والتشغيل السريع (كيف تجعل كمبيوترك سيرفراً متاحاً للعالم؟)

لكي تجعل جهازك سيرفر ذكاء اصطناعي يعمل 24/7 ويستقبل الطلبات من أي مكان، اتبع هذه الخطوات:

### 1️⃣ التحميل والتثبيت (مرة واحدة فقط)
1. قم بتحميل أو استنساخ المشروع على جهازك:
   ```bash
   git clone https://github.com/Amino997h/local-API.git
   ```
2. انقر مرتين على ملف: **`Install_Requirements.bat`**  
   *(سيقوم بفحص بايثون وتثبيت المكاتب ومتصفح Playwright Chromium تلقائياً)*.

---

### 2️⃣ إعداد نفق الربط الخارجي Ngrok (مرة واحدة فقط لفتح السيرفر للعالم)
إذا أردت الوصول إلى سيرفرك من الخارج (أو من جهاز آخر أو سيرفر سحابي):
1. سجل حساباً مجانياً على موقع **[ngrok.com](https://ngrok.com/)**.
2. ثبّت أداة `ngrok` على جهازك (أو عبر الأمر: `winget install ngrok`).
3. افتح موجه الأوامر (CMD) واربط حسابك لمرة واحدة فقط:
   ```bash
   ngrok config add-authtoken <التوكن_الخاص_بك>
   ```

---

### 3️⃣ تشغيل السيرفر وتسجيل الدخول
1. انقر مرتين على ملف: **`Run_Server.bat`**
2. ستفتح نافذتان:
   - **نافذة السيرفر:** وسيفتح معها متصفح Chrome، قم **بتسجيل الدخول إلى حساب ChatGPT** لمرة واحدة (ستظل الجلسة محفوظة للأبد).
   - **نافذة Ngrok:** ستعرض لك الرابط الخارجي المباشر الخاص بسيرفرك، مثل:
     ```text
     Forwarding: https://xxxx-xx-xx.ngrok-free.dev -> http://localhost:8008
     ```

---

## 🔑 كيفية استخدام السيرفر والربط به (من جهازك أو من أي مكان)

الآن أصبح جهازك سيرفر متكامل، ويمكن لأي تطبيق (مثل n8n، Cursor، TypingMind، أطر العمل AI) الاتصال به عبر:

- **الرابط الخارجي (من خارج جهازك):** `https://xxxx-xx-xx.ngrok-free.dev/v1` *(رابط الـ Ngrok الظاهر عندك)*
- **الرابط المحلي (من داخل نفس جهازك):** `http://127.0.0.1:8008/v1`
- **مفتاح الحماية (API Key):** `sk-chatgpt-local-secret-key` *(أو المفتاح الذي تحدده في `config.py`)*
- **النموذج (Model):** `gpt-4o` (أو `gpt-4` / `gpt-3.5-turbo`)

## 🧪 اختبار السيرفر محلياً

يمكنك تشغيل سكريبت الاختبار في نافذة جديدة:

```bash
python test_client.py
```

أو استخدام `curl`:

```bash
curl -X POST http://127.0.0.1:8008/v1/chat/completions \
  -H "Authorization: Bearer sk-chatgpt-local-secret-key" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-4o",
    "messages": [{"role": "user", "content": "مرحبا، من أنت؟"}]
  }'
```

## ⚙️ الإعدادات (`config.py`)

يمكنك تخصيص الإعدادات التالية داخل `config.py`:
- `API_KEY`: رمز الحماية للطلبات.
- `PORT`: منفذ السيرفر المحلي (الافتراضي 8008).
- `RESPONSE_TIMEOUT_SECONDS`: مهلة انتظار التوليد (الافتراضي 120 ثانية).
- `PROFILE_DIR`: مسار المجلد الدائم لجلسة المتصفح.
